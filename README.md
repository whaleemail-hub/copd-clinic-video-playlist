# COPD 門診候診影片播放專案

這是一個獨立於 COPD 互動衛教網站的候診區影片輪播專案，目標是在門診區電視播放衛教影片。

## 設計目標

- 將原本網站的「影片專區」獨立成門診播放用專案。
- 提供 4 種不同播放組合。
- 可為每種組合設定不同循環次數。
- 組合 A 已依實際片長校正，單輪約 53 分鐘，目前設定循環 3 次，約 2 小時 40 分鐘。
- 其他組合暫以估計片長與 2 次循環規劃，待確認實際片長後再校正。
- 吸入劑示範影片較短，每組安排約 4-5 種吸入劑，再搭配其他衛教影片。

## 四種組合

- 組合 A：基礎認識與常見吸入劑
- 組合 B：急性警訊與定量噴霧吸入劑
- 組合 C：三合一吸入劑與日常照護
- 組合 D：復健運動與居家安全

## 影片時長

目前 `src/videoData.ts` 中的 `durationSeconds` 有兩種狀態：

- 組合 A 中已確認的影片使用實際片長。
- 尚未確認的影片仍使用估計值。

影片來源包含：

- YouTube
- 台大媒體平台
- Google Drive
- MP4 檔案

這些來源不一定都能穩定自動讀取影片時長。候診播放器會依照 `durationSeconds` 自動切換下一支影片。

若未來確認實際片長，只要修改：

```ts
durationSeconds: 10 * 60
```

即可重新計算每組總長度。

## 本機執行

```bash
npm install
npm run dev
```

預設網址：

```text
http://localhost:3100/
```

## 部署

可部署到 Vercel、Render Static Site、Netlify，或用 GitHub Pages。

建議設定：

- Build command: `npm run build`
- Publish directory: `dist`

## 注意事項

- 若瀏覽器阻擋自動播放，請先點一次播放或使用「下一支」。
- YouTube、Google Drive、台大媒體平台可能因來源網站政策影響自動播放。
- 若要最穩定在電視循環播放，最佳做法是日後取得影片檔案並改為本地 MP4 或院內伺服器影片來源。
